# Nino — studio vidéo local

L'application **Nino** est développée dans [`studio/`](studio/README.md) :
projets sauvegardés, préparation de la salle, contrôle OBS, enregistrement et
diffusion live, avec une API commune pour le PC, l'iPad et le Stream Deck.

Consulter le [guide de développement et de livraison](studio/docs/development.md)
pour les tests et le workflow GitHub Actions. Node.js 24 ou supérieur est requis.
Les vidéos et la base de la salle restent locales.

Le [guide d'installation de la salle (PDF)](studio/docs/guides/nino-installation-salle.pdf)
décrit les branchements des trois Sony ZV-E10, des quatre Cam Link et de la
RØDECaster Pro II, puis les réglages Windows, OBS et Nino jusqu'au premier MP4.

La documentation complète est dans [`studio/README.md`](studio/README.md).
